# Admission PDFs

This directory is intentionally empty in the public repository.

The clinical admission PDFs used in the Anamnesis benchmark are derived from MIMIC-III and are therefore **not redistributed here**.

To reproduce the benchmark dataset, credentialed PhysioNet users must obtain access to MIMIC-III and rebuild the admission PDFs locally using the scripts provided in:

`rebuild_anamnesis/`

Those scripts reproduce the PDF corpus used by the project from the authorized source data.

The synthetic example PDFs, when provided, are stored separately and are intended only for demonstration or smoke testing. They were **not** used to produce the results reported in the paper.
